This is the demo garden for **kvist**, a tool that publishes selected notes from an Obsidian vault as a website like this one. It is written like a real garden: notes about [[Garden|growing food]], [[Kitchen|cooking it]], [[Ideas|thinking in notes]], a few [[Projects|projects]] and some [[Books|books]]. Hover any link to preview it.

![[sprout.svg|center|96]]

## Where to start

- **New here?** Read [[About]] and what I'm doing [[Now|now]].
- **The garden:** start with [[Soil]], then [[Composting]] and [[Tomatoes]].
- **The kitchen:** [[Sourdough]] is the longest note, with a schedule table.
- **The ideas:** [[Digital gardens]] explains why a site like this exists.
- **The tour:** [[Features]] shows everything kvist renders, one note per feature.

## What stays private

Some notes in this vault are private, and you can't tell them from notes that don't exist. [[Diary]] lives in a private folder, [[Draft]] opts out with `publish: false`, and [[Secret corner]] carries a `#private` tag. All three render as muted text, exactly like [[No such note]]. See [[How publishing works]] for the rules.

> [!tip] Try it
> Press <kbd>/</kbd> to search, open the **Graph** from the menu, or hover a heading and click the `#` to copy a link to it.
