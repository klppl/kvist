Review things just before you'd forget them. Each successful review pushes the next one further out.

A simple model of forgetting is an exponential decay of recall $R$ over time $t$, with memory stability $S$:

$$
R = e^{-t/S}
$$

Each review increases $S$, so the curve flattens. I don't use flashcards for gardening, but the same idea is behind revisiting old notes: tending them is a kind of review.
